# Mahaveer Enterprises Product Showcase Website

A modern, responsive website showcasing Mahaveer Enterprises' products across three main categories: Furniture, Electronics, and Networking items.

## Features

- Responsive design that works on all devices
- Interactive product slider on the home page
- Category-based product browsing
- Product search functionality
- Category filtering
- Mobile-friendly navigation
- Detailed product pages with:
  - Multiple product images
  - Comprehensive product descriptions
  - Detailed specifications
  - Category information
  - Image gallery with thumbnails

## Setup Instructions

1. Clone the repository
2. Open `index.html` in your web browser
3. For development, use a local server (e.g., Live Server in VS Code)

## Required Images

### Slider Images
- `images/slider1.jpg`
- `images/slider2.jpg`
- `images/slider3.jpg`

### Category Card Images
- `images/furniture-category.jpg`
- `images/electronics-category.jpg`
- `images/networking-category.jpg`

### Product Images
Each product requires the following images:
- Main product image (e.g., `images/furniture1.jpg`)
- Three detail images (e.g., `images/furniture1-detail1.jpg`, `images/furniture1-detail2.jpg`, `images/furniture1-detail3.jpg`)

## Navigation

- Home: Returns to the main page
- All Products: Shows all products with search and filter options
- Furniture: Shows furniture products
- Electronics: Shows electronics products
- Networking: Shows networking products

## Search and Filtering

- Use the search bar to find products by name or description
- Filter products by category using the category buttons
- Search works in both desktop and mobile views

## Product Details

- Click on any product card to view its detailed page
- Product detail pages include:
  - Main product image with thumbnail gallery
  - Product name and category
  - Detailed description
  - Comprehensive specifications
  - Additional product images
